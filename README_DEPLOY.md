# GPR v8 온라인 배포용

## GitHub
이 폴더 안의 파일 전체를 새 GitHub repository 최상위에 업로드합니다.

## Streamlit Community Cloud
1. https://share.streamlit.io 접속
2. GitHub 로그인
3. Create app
4. Repository 선택
5. Branch: main
6. Main file path: app.py
7. Deploy

배포가 끝나면 `https://원하는이름.streamlit.app` 형태의 주소가 생성됩니다.
이 주소를 공유하면 다른 사람은 Python 설치 없이 브라우저에서 사용할 수 있습니다.
